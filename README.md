# Gyanpath NGO — Fixed Build

Flask NGO website with public pages, customer/staff/admin foundations, project and enquiry management, responsive premium UI, and optional Three.js hero.

## Run

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python seed.py
python verify_app.py
python run.py
```
